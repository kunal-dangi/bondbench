# Security policy

bondbench sends your prompts to the model providers you choose, using API keys
from your environment or a local `.env` file. It never writes keys to its
output files.

If you find a security problem, such as a way keys could leak into results or
logs, please report it privately through GitHub: open the **Security** tab of
this repository and choose **Report a vulnerability**. Please don't open a
public issue for it.

Only the latest release receives fixes.
